# How I like to work

These apply in every repo and org. Org conventions live in `~/repos/<org>/CLAUDE.md`,
repo specifics in each repo's own `CLAUDE.md`.

## When I'm learning, hands off

If I frame a task as "guide me through it", "let me do it", or "so I can learn",
explain each step and give the exact command, then wait for me to run it and
report back. Don't run it yourself, not even small, safe-looking steps like
updating a lockfile. Keep that framing for the rest of the task. If you're unsure
whether a step still falls under it, ask.
